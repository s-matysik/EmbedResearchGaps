EmbedResearchGaps

Embedding-driven identification of candidate research gaps in author-keyword space.

EmbedResearchGaps turns the author-keyword space of a screened corpus into a short, typed, source-linked list of candidate research gaps, and measures how reproducible that list is. Formulating a gap stays a creative act; what the package contributes is a shortlist stripped of trivial and already-covered terms, with its stability reported rather than assumed.

Install it, point it at a CSV export, run either mode, read the candidate table.

Install#

git clone https://github.com/s-matysik/EmbedResearchGaps.git
cd EmbedResearchGaps
pip install -e .

Quick start#

from embedresearchgaps import load_csv, RunConfig, articles_first

corpus = load_csv("scopus.csv")
result = articles_first(corpus, RunConfig(top_n_articles=50))

print(result.gaps[["gap_type", "keyword", "score", "rationale"]].head())
result.save("results")

Or from the shell:

embedresearchgaps run scopus.csv --mode articles_first --top-n 50 --figures

The two modes#

ModeWhat it clustersWhat it flags
keywords_firstthe unique author keywords keywords whose distance from their own cluster centroid exceeds a cluster-specific percentile
articles_firstthe articles emerging concepts, unrealised combinations and cross-cluster concepts inside each cluster's keyword sub-space

Both return a PipelineResult: a candidate table with scores, metrics, rationales and source records, plus the diagnostics a methods section needs. A ranking produced by another tool enters the same object through load_external_ranking, so the assessment layer applies to it unchanged.
